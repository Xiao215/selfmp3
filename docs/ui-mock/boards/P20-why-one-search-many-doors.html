One search, many doors Home's field, the search circle in the bar and Library's field all open the same Search page. Where you came from only picks the scope it starts on: All from Home, Songs from Library, Tags from the Tags page. One tap changes scope. Before you type it shows your tags and what you played last; it keeps no search history. On a computer the same page is ⌘K, the field on Home, and the field in a list header.
